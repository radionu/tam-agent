# TAM Agent

Client software and release distribution for TAM (Telemetry, Alerting and Monitoring).

## Status

This repository is being initialized. No installable managed agent release is published here yet.

The planned client supports outbound communication with TAM Center, device enrollment, heartbeat telemetry and centrally managed updates. Installation instructions and supported platforms will be documented with verified releases.

The TAM Center download address is https://tam.pmr.vn/downloads/. Availability of a working installer will be announced with the release instructions.

## Development

Changes are developed on task branches and reviewed through pull requests. Keep documentation in English. Do not commit credentials, enrollment tokens, private keys, device state or customer data.
